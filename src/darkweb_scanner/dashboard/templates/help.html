Signing in

  • Two-factor sign-in is mandatory. A new account must replace its temporary password and enrol an authenticator app before it can open anything else. There is no way to skip this.
  • Passwords: at least 12 characters, with an uppercase letter, a lowercase letter, a number and a symbol.
  • Each code works once. A six-digit code that has been used is refused if it is entered again.
  • Lockouts. After 10 wrong passwords for one user name, or 20 failed attempts from one address, within 15 minutes, sign-in is refused for 15 minutes. After 5 wrong codes the second step is locked for 15 minutes and the password has to be entered again. An administrator can lift a lock from the server (see the runbook).
  • Sessions end 12 hours after sign-in. Signing out, changing your password or changing your second factor ends your sessions on every other device as well. Deleting a user ends that user's sessions at once.
  • Replacing your authenticator (Settings) needs a code from the current one. Removing it needs your password and a current code, and you are asked to enrol again straight away.
  • Lost your authenticator? Ask an administrator to reset your second factor. You then enrol a new one at your next sign-in.

Channel Monitor ADMIN

Channel Monitor reads messages from a public Telegram channel through the Telegram account configured on the server, translates them to English and packs the result into a ZIP archive.

  • Public channels only. Only a public channel user name (@name or a t.me/name link) is accepted. Private chats, saved messages, phone numbers, numeric ids and invite links are refused.
  • Translation is done by Google Translate. The text of every message that is not detected as English is sent from this server to Google's public translation service. No account or key is used; media files, sender names and the channel name are not sent. Do not run it on a channel whose content must not be disclosed to Google.
  • Who can see jobs. Only administrators can start a job, see the job list and logs, and download or delete an archive. Each job records the administrator who started it.
  • Retention. Archives and their job folders are deleted automatically {{ retention_days }} days after the job last wrote to them. Download what you need to keep.
  • The report file (messages.html in the archive) contains no scripts and loads nothing from the internet; channel content is shown as text.

What is stored and logged

  • Your account: user name, e-mail address if one was given, a bcrypt hash of your password, your authenticator secret, the time of your last sign-in.
  • Sign-in log: successful and failed sign-ins, lockouts, sign-outs, password and second-factor changes and user administration, each with the time, the user name and the network address it came from. Kept for 365 days. Administrators can read it.
  • Web server log: every request with the visitor's address, kept in rotating container logs.
  • Work data: crawl results and hits, investigations, projects, Quick Scan results, the keyword, seed and channel lists, digest subscribers, and Channel Monitor archives (for {{ retention_days }} days).
  • Where: on the server that runs this platform, in its PostgreSQL database and data volume, and in that server's backups. Nothing is sent to the software's authors.
